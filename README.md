# Learn Python: Interactive Learning Site

An interactive website where beginners learn Python in the browser.
Learners read a short lesson, write code, click Run, and get instant feedback.

**Live demo:** (https://ochiengemmanuel5562-create.github.io/python-learning-site/)

## Features
- Runs real Python in the browser using Pyodide (no server needed)
- Automatic answer checking with hints and a "Show solution" option
- Progress tracking saved in the browser with localStorage
- Responsive layout for phones and desktops
- Lessons stored as data, so new lessons need no new code

## Built with
HTML, CSS, JavaScript, Pyodide, GitHub Pages

## What I learned
Building the DOM-driven interface, handling async code loading,
persisting state with JSON, and separating content from logic.
